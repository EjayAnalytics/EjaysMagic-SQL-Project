## PROJECT OVERVIEW
EjaysMagic is a SQL server database project created to analyse and manage data for a handmade crochet business. 
The project demonstrates how a relational database can be designed to organise products, product sizes, customers, orders and
orders details.

## TOOLS AND TECHNOLOGIES
* SQL Server
* SQL Server Management Studio(SSMS)
* GitHub

## DATABASE TABLES
* Products - stores products information and selling prices.
* Product Sizes - stores available sizes for selected products.
* Customers - stores customer information.
* Orders - records customer orders, dates and order totals.
* Orders Details - records the individual products included in each order.

## DATABASE RELATIONSHIP
  The project uses primary and foreign keys to establish relationship between tables and maintain data integrity.

## SQL SKILLS DEMONSTRATED
  * Creating and managing relational database.
  * Creating tables and defining data types.
  * Using primary and foreign keys.
  * Applying constraints.
  * Inserting and managing data.
  * Establishing relationships between tables.
  * Joining multiple tables.
  * Aggregating and analysing sales data.
 
 ## PROJECT FILES 
    EjaysMagic_project.sql - contains the SQL code used to create and populate the database.
    EjaysMagic_Data_Analysis.sql - contains SQL queries used to analyse product sales, quantities, pricing and revenue.

 ## DATA ANALYSIS
   The project includes SQL analysis of product sales and revenue using data stored in the EjaysMagic database.
   The analysis demonstrates the use of:
   - SELECT and WHERE
   - ORDER BY and TOP
   - SUM, COUNT and AVG
   - GROUP BY and HAVING
   - JOIN
   - DISTINCT
   - IS NULL and IS NOT NULL
   - CASE statements
   - Calculated fields for sales revenue.

  ## KEY FINDINGS
   - Total recorded sales revenue was £545.
   - Crochet Doll generated the highest revenue at £240.
   - Crochet scrunchie had the highest sales volume with 6 units sold.
   - Crochet shorts generated £140 in revenue from 4 units sold.
   - 7 out of the 10 products appeared in the recorded sales data.
   - The highest-selling product by quantity was not the highest revenue-generating product.
